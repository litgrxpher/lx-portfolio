# Litgrxpher · Visual Archive & Portfolio

> *"Querying data by day, framing stories by night."*  
> The photography, film, and interactive portfolio of **Adharsh CS** ([@litgrxpher](https://www.instagram.com/litgrxpher/)).

## Tech Stack & Architecture

* **Framework**: React 18 + Vite
* **3D Graphics & Shaders**: Three.js, GLTFLoader, custom GLSL shaders
* **Animation & Orchestration**: GSAP 3, ScrollTrigger, Framer Motion
* **Audio Synthesis**: Web Audio API (procedural wind, LFO gusts, UI sound FX)
* **Smooth Scrolling**: Lenis (desktop mouse wheels) + Native 120Hz compositor touch scrolling on mobile
* **Typography**: *Bricolage Grotesque*, *Geist*, *Inter Tight*
* **Styling**: Tailwind CSS + custom CSS custom properties
